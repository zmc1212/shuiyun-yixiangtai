# 水运仪象台 SHUIYUN-YIXIANGTAI — 机构复刻 No.16(旗舰)

苏颂《新仪象法要》(1092)五层塔:平水壶注水入枢轮受水斗,斗满失衡下转,
天关抵轮、天锁锁止——间歇步进传动(擒纵机构之先声,早于欧洲约六百年)。
枢轮 36 斗步进角 10°,36 步恰一周,昼夜机轮随动,顶部浑仪。
B 键查看剖视图与擒纵时序。

## 机构与验算

```
尺寸(演示值):
  塔架   五层,高 5.6 m(文献五丈六尺),W 2.3 m
  枢轮   R 0.85,36 受水斗 → 步进角 2π/36 = 10°
  擒纵   天关(左杠杆)+ 天锁(右锁杆),间歇锁止
  平水壶 注水入斗,水头恒定
  昼夜机轮 五层小轮(天柱直传随动);顶部浑仪三环

运动学(载入期断言):
  锁止注水 1.6s → 步进 0.55s(转过 10°)
  每步转角与 2π/36 偏差 < 1e-9;36 步恰整周(模拟 40 步断言)
```
